# 🌱 PlantCare AI – Plant Disease Recognition System

An AI-powered plant disease recognition system built using **Deep Learning and EfficientNetB4**. The model analyzes leaf images and classifies them into 39 plant health and disease categories.

## 🚀 Project Overview

PlantCare AI uses transfer learning and fine-tuning with the EfficientNetB4 architecture to identify plant diseases from leaf images.

The project aims to support early plant disease identification through image classification.

## ✨ Features

- Plant leaf image classification
- 39 plant health and disease classes
- EfficientNetB4 architecture
- Transfer learning and fine-tuning
- Top-5 prediction results with confidence scores
- Model evaluation using classification metrics
- Confusion matrix visualization

## 🧠 Model Information

| Parameter | Details |
|---|---|
| Model Architecture | EfficientNetB4 |
| Learning Approach | Transfer Learning |
| Fine-Tuning | Yes |
| Image Size | 160 × 160 |
| Number of Classes | 39 |
| Training Images | 49,179 |
| Validation Images | 6,139 |
| Testing Images | 6,168 |
| Test Accuracy | 98.28% |

*The reported accuracy is based on the project's current dataset split and is not a guarantee of performance on real-world field images.*

## ⚙️ Model Usage

1. Download the trained model and class names file.
2. Load the EfficientNetB4 model using TensorFlow/Keras.
3. Upload a plant leaf image.
4. Preprocess the image to 160 × 160 pixels.
5. Generate predictions and display the predicted class.
